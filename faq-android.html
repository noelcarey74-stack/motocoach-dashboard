FAQ Android

Last updated: 4 January 2026

MotoCoach (Android) is built for closed-circuit track days. Right now the app focuses on: Video + GPS lap timing and saving sessions on your device.

General

What does MotoCoach (Android) do?

MotoCoach lets you record on-bike video while tracking GPS position and lap timing. You set a start line, arm the session, and the app starts timing automatically once you move off (using a speed gate). Each lap is detected when you cross the start line again.

Do I need an account or login?

No. There’s no account system in the Android build right now. Sessions are saved locally on your phone.

Does MotoCoach need mobile signal?

No. GPS + lap timing + video recording can work without mobile signal. (GPS uses satellites; you don’t need data for timing.)

Video + GPS

How do I start a session properly?

Recommended flow:

1) Open Video + GPS
2) Wait for GPS accuracy to improve (you’ll see it as ± metres)
3) Tap Set start line exactly where you want laps to trigger
4) Tap Press out / Arm
5) Ride out — timing + video starts once you hit the start speed gate (e.g. 25 km/h)

Tip: set the start line while you are stationary on the racing line (or as close as safely possible).

Why does the speed show 0 before the run starts?

This is intentional. The speed display stays at 0 until the run actually starts, so it doesn’t show “dirty” low speeds when you’re standing still or creeping in the pits. Once the run starts, the speed shows the real value and can drop below the gate speed normally.

What files does the app save?

When you save a session, MotoCoach can store:

  • Video file (recorded during the run)
  • Telemetry JSON (GPS samples used for playback + lap data)
  • Session summary (laps, track name, notes)

These are saved on your device (app storage), and you can browse them in Video + GPS Sessions.

GPS & accuracy

It says “acquiring…” or accuracy looks poor — what do I do?

GPS can take longer depending on phone model, weather, and surroundings. For best results:

  • Go outside with a clear view of the sky (away from tall buildings).
  • Give it 30–90 seconds to settle before setting the start line.
  • Turn on phone location services and allow “Precise location”.
  • If you just enabled location, close and reopen the app.
Will it still work if GPS accuracy isn’t perfect?

It can still work, but start-line precision matters for consistent lap triggers. If accuracy is very poor, lap triggers may happen early/late. Best practice is to set the start line once GPS has settled to a reasonable accuracy.

Safety

Can I use MotoCoach on public roads?

No. MotoCoach is intended for closed-circuit track use only. Do not interact with the app while riding or driving.

Mounting advice

Use a secure mount appropriate for your vehicle and track rules. Make sure the phone does not obstruct your view or any controls. Set everything up in the paddock and leave it alone during the session.
